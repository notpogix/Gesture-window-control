# Gesture Window Control

Control the Windows mouse cursor and move desktop windows using hand gestures and a webcam.

## Features

- Move the cursor using your index finger
- Pinch thumb and index finger to grab a window
- Move the grabbed window with your hand
- Release the pinch to release the window
- Real-time hand tracking and gesture visualization
- Adjustable sensitivity, smoothing, and gesture thresholds
- Runs locally with no cloud services or paid APIs

## Requirements

- Windows 10 or 11
- Python 3.10, 3.11, or 3.12
- Webcam
